# 律师使用说明书

适用版本：当前本地实现版，面向律师和律所管理员。

## 1. 登录与个人设置

1. 打开系统地址，使用邮箱和密码登录。
2. 首次注册时必须填写律所/公司名称，系统会自动创建组织。
3. 进入「设置」→「个人信息」，维护姓名、联系电话，并查看所属公司/律所。
4. 进入「设置」→「外观」，可选择「明亮版」或「经典暗色版」。
5. 进入「设置」→「模型设置」，配置律所使用的大模型 Provider、模型名、Base URL 和 API Key。

## 2. 创建和维护案件

1. 进入「案件管理」，点击「新建案件」。
2. 填写案件标题、案件类型、客户姓名、客户邮箱或客户电话。
3. 客户邮箱和电话至少填写一个；后续可在案件列表中点击编辑按钮修改。
4. 律师可在案件编辑弹窗或案件详情页修改案件状态：
   接案、事实提取、文案起草、律师审核、已递交。
5. 案件详情页会展示案件类型、客户姓名、客户邮箱、客户电话和当前状态。

## 3. 上传和解析文档

1. 进入某个案件后，打开「文件管理」。
2. 选择文件类型，例如证据材料、获奖证明、专利、论文、引用数据、雇佣证明、媒体报道、推荐信等。
3. 拖拽或点击上传文件。
4. 上传后不会自动解析，律师需要点击「AI 解析」。
5. 解析弹窗可输入律师提示词，也可从知识库检索并载入提示词模板。
6. 文档列表提供两个下载动作：「原始文件」下载上传原件；「解析文案」导出当前文档已提取的全部事实。

## 4. 事实库审核

1. 进入「事实库」查看系统从文档中抽取的事实。
2. 一篇文档可以产生 0 条、1 条或多条事实，系统不会限制为一条。
3. 每条事实显示修改时间，可按修改时间升序或降序排序，便于核对最近解析、编辑或重解析的事实。
4. 律师可对事实执行：
   确认、取消确认、编辑、翻译、删除、恢复。
5. 如果事实有异议，点击「有异议」，填写异议意见后选择「重新解析」。
6. 系统会根据原事实、律师异议和可读取的来源文档文本重新生成事实，并把状态重置为待审核。
7. 对需要客户补充材料的事实，可提交补材料任务到任务中心。

## 5. 生成和修改文案

1. 进入「文案工作台」。
2. 选择要使用的事实和知识库材料。
3. 输入生成要求，选择策略后触发 Agent 生成文案。
4. Agent 会优先使用律师确认事实，也会参考选中的知识库材料、历史样例和策略说明。
5. 文案列表显示修改时间，可按修改时间排序，最近生成、编辑或重写的文案会更容易定位。
6. 律师可对文案段落进行编辑、重写、翻译、导出和版本恢复。
7. 所有大模型输出会在后端清理 `<think>` 推理标签，再进入页面和数据库。

## 6. 任务中心

1. 「任务中心」用于管理待办、补材料请求、审核事项和 Agent 相关任务。
2. 律师可新建任务、修改任务状态、标记已完成、删除或恢复任务。
3. 任务显示修改时间，可按修改时间升序或降序排序；状态变更、完成、重开都会更新该时间。
4. 全局任务页可跨案件查看待办；案件内任务页只展示当前案件任务。

## 7. 知识库

1. 知识库可保存提示词模板、文档模板、历史样例和 Agent 策略。
2. 文档解析和文案生成弹窗都支持检索知识库内容。
3. 建议把常用 EB-1A/NIW 论证框架、律所固定表达、证据审核清单保存为模板。

## 8. 推荐工作流

1. 新建案件并录入客户联系方式。
2. 上传客户材料，按文件类型归类。
3. 对每篇关键文档执行 AI 解析，并用提示词控制抽取重点。
4. 在事实库逐条确认、编辑或提出异议。
5. 生成文案前，只选择已经确认或可信度较高的事实。
6. 生成文案后由律师逐段审核，必要时用重写功能调整表达。
7. 对缺失材料创建任务，材料补齐后重新解析并更新文案。

## 9. 注意事项

- AI 输出只能作为律师草稿辅助，不能替代律师审查。
- 事实确认前不要直接用于最终递交文案。
- 客户联系方式应保持最新，便于补材料和案件沟通。
- 上传材料涉及隐私和商业秘密，建议仅部署在律所认可的服务器或私有环境中。
